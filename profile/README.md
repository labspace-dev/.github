Student Labs

A centralized repository for storing, managing, and automatically deploying student laboratory assignments.

Purpose

The project provides a centralized environment where students can submit their code, which is then deployed and executed on a remote server.

Features

* Code Storage — centralized storage for student laboratory assignments.
* Automated Deployment — automatic deployment of submitted code to the server.
* Code Execution — running and testing assignments in a server environment.
* Submission Tracking — organizing submissions and maintaining assignment records.

Intended Audience

Students and instructors involved in the educational process.
